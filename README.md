# Astra

Astra — многофункциональный Jabber (XMPP) бот для администрирования конференций (MUC).
Бот подключается к XMPP-серверу, заходит в заданный список комнат, следит за присутствием
участников, обрабатывает текстовые команды, управляет правами и ролями, ведёт статистику
и реализует множество игр и утилит.

Реализован на **Python 3 + slixmpp 1.17** с собственным слоем совместимости (`xmpp.py`),
эмулирующим legacy-API `xmpppy`, поверх которого построено ядро (`astra.py`) и ~209 плагинов.

---

## Назначение

- **Администрирование конференций**: вход в комнаты, права доступа, роли/аффилиации
  (модератор/админ/овире), кик, бан, мембер, приглашения.
- **Защита**: антибот, антиспам, антивайп, антиспэйс, flood-контроль, ростер-верификация,
  IQ-взломостойкость, приват-листы.
- **Развлечения и игры**: викторина, миллионер, очко (21), снежки, морской бой, рулетка,
  дуэль, тамагочи, таро, крестики-нолики и др.
- **Утилиты**: погода, перевод, поиск, расстояние между городами, DNS, vCard, время,
  ping, статистика, сокращение ссылок и многие другие.

Каждая возможная команда — отдельный плагин в каталоге `extensions/`; справочники команд —
в каталоге `help/`.

---

## Происхождение

Astra — порт и переработка классического бота **BlackSmith mark.1** (XMPP/Jabber).

Бот создан командой «Witcher»; развитие продолжала команда «simpleApps» (simpleapps.ru).
Исходные версии писались под Python 2; Astra переведена на современный **Python 3** и
асинхронную XMPP-библиотеку **slixmpp** через слой совместимости с legacy-API `xmpppy`.

## Системные требования

- **Python 3** (проект портирован с Python 2; поддерживаются legacy-алиасы
  `basestring`, `unichr`, `unicode`, `file`).
- **slixmpp == 1.17.0** (асинхронная XMPP-библиотека).
- **requests** (для сетевых операций плагинов).
- **Операционная система Unix-подобная** (Linux): используются `os.uname()`,
  `ps -o rss` (проверка памяти) и `os.execl` (перезапуск).

## Установка и конфигурация

1. Скопируйте шаблон конфигурации и откройте его для редактирования:

   ```bash
   cp config.example.py config.py
   ```

2. Заполните параметры подключения в `config.py`:

   | Переменная | Описание |
   |---|---|
   | `SERVER` / `CONNECT_SERVER` / `HOST` | XMPP-домен и сервер подключения |
   | `PORT` | TCP-порт (5222 или 5223) |
   | `SECURE` | `True` — использовать TLS |
   | `USERNAME` / `PASSWORD` / `RESOURCE` | учётные данные JID бота |
   | `DEFAULT_NICK` | ник бота в комнате по умолчанию |
   | `BOSS` | JID суперадмина (уровень доступа 100) |

3. Установите зависимости:

   ```bash
   pip install slixmpp==1.17.0 requests
   ```

Каталоги `dynamic/`, `faillog/`, `logs/` создаются ботом автоматически при первом запуске
(файл `config.py` внесён в `.gitignore` и служебные данные в репозиторий не попадают).

---

## Запуск

```bash
python3 astra.py
```

Бот подключается к серверу, авторизуется, входит в комнаты, перечисленные в
`dynamic/chats.txt`, после чего начинает обрабатывать команды и сообщения.

Для входа в новую конференцию администратор командует из ростера:

```
джойн <конференция>@conference.<домен>
```

Полный перечень команд бот выводит командой `команды` (или `хелп`/`помощь`).
